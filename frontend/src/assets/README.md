# Interface assets

`saturn.webp` is a locally bundled WebP conversion of NASA/JPL-Caltech's
**A View of the Rings of Saturn** (PIA22766), used as visual inspiration on the
new-reel screen. It is not presented as a generated film.

- Source and credit: https://www.nasa.gov/image-article/view-of-rings-of-saturn/
- Original: https://www.nasa.gov/wp-content/uploads/2023/03/pia22766-nasa.jpg
- Credit displayed in the interface: NASA / JPL-Caltech.
- NASA media guidance: https://www.nasa.gov/nasa-brand-center/images-and-media/

Inter is bundled through `@fontsource-variable/inter` under the SIL Open Font
License. Fonts and imagery load from the built application, without third-party
requests. The small interface icons are inline SVGs in `components/Icon.tsx`.
